# Roadmap

## Now
- Run the agent eval and publish `evals/results.md`.
- Deploy the web app (Streamlit Community Cloud) for a public demo link.
- Add 👍/👎 feedback; thumbs-down answers become new eval cases.

## Next
- **Average daily balance** interest calculation, to match real card accounting.
- **"Explain my statement" summary** on first open, so customers don't have to know what to ask.
- **Dispute pre-fill:** when escalating, attach the transaction, flags and conversation so the specialist starts with full context (measure handle-time saved).
- **Held-out eval set** written by someone other than the builder.

## Later
- **Proactive alerts:** notify before a promo APR ends or when a subscription price rises.
- **Multi-language explanations.**
- **Approved actions** (e.g. auto-credit a confirmed duplicate under $X) only after the escalation data shows near-perfect precision and risk sign-off.

## Explicitly not planned
- Investment or debt advice. It's a different regulatory category and a different product.
